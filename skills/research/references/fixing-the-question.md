# Fixing the question

An area is not a question. "Whether to acquire the supplier" is an area. "Does
the supplier's order book survive the loss of its largest customer" is a
question, because something would answer it.

Before collection starts, the question passes three tests.

- **Specific.** It names the thing, the period, and the population.
- **Measurable.** You can name the observable that answers it.
- **Free of its own answer.** "Why is the rollout failing" presumes failure.
  Ask whether it is failing, then why.

Where someone else set the question, settle any difference between their
wording and yours with them before working. A delegated agent that cannot reach
them records both wordings, marks the difference, and proceeds. It claims no
approval it never got.
