# Collection: planning and finding

## Plan the collection

**What would answer it.** For each candidate answer, name the observable that
would establish it: a thing that either is or is not the case, not a topic to
read about.

**What would break it.** For each candidate answer, name what you would expect
to see if it were true and are not seeing, and what you would expect to see if
it were false.

Then order the work.

- Turn the question into named requirements, decide which source could satisfy
  each, and keep checking whether the collection satisfies them. Revise the
  plan as findings change it.
- Go after what discriminates first. A document that fits every candidate
  answer equally well tells you nothing, however solid.
- Go after what expires first: a person leaving, a log with a retention window,
  a page that changes weekly.

## Find candidates

First work out what kinds of source exist for this question. Then gather the
candidate list before examining any of it in detail.

Vary where you look, not just how much. A search engine, an official register,
the originator's own publications, a regulator's filings, and a person who was
there return different material.
