# Lookup mode

1. Write the question in one sentence. If you cannot, you have an area rather
   than a question: fix it at full mode step 1.
2. Read a few documents. Store each the way cite mode stores one.
3. Answer directly. Every claim cites the stored document it rests on. Mark a
   claim you infer rather than read.
4. Note the dead ends in a sentence: what you opened that gave you nothing.

No handover contract, check record, collection plan, or tables.
