# The heavy challenge techniques

- **Analysis of competing hypotheses.** List every reasonable hypothesis
  first, then array all the evidence against all of them at once in a matrix,
  each cell marked consistent, inconsistent, or not applicable. Work by
  disproving, not proving.
- **Team A and Team B.** Two defensible views rather than one dominant one ->
  build the best case for each, with explicit assumptions, evidence, and
  logic, then let a third party question both.
- **Devil's advocacy.** Consensus firm -> build the best case for the
  alternative, find the faulty logic or evidence that would undermine the
  judgment, and label the product explicitly as devil's advocacy so nobody
  mistakes it for the finding.
- **Red team.** Model the other party's reasoning from inside their setting,
  with first-person questions, to avoid mirror-imaging your own motives onto
  them. A red team product carries no caveats and represents no consensus, so
  label it as one.
