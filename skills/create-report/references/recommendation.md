# The recommendation handover

## Send it back, or draft from the handover

Check the analysis handover against every standard below. Two moves are
compliant, and there is no third:

- Draft from what was handed over.
- Send it back. Analysis that owed a criterion, a weight, or a matrix and
  arrives without one has a gap this skill cannot close: say so.

Never write a criterion, set a weight, or build a matrix here.

## At least two distinct options

A single option is admissible only where the analysis defends why no
alternative exists.

## Criteria set before the options, and frozen

Criteria come before options and take no new member once analysis has
started. Screening criteria apply first, then evaluation criteria.

## Screening criteria

A pass or fail gate before any scoring. An option that fails one is out, and
the report says so rather than scoring it low and keeping it.

- Feasible: fits within available resources.
- Acceptable: worth the cost or risk.
- Suitable: solves the problem and is legal and ethical.
- Distinguishable: differs significantly from other solutions.
- Complete: covers the critical aspects of the problem from start to finish.

Every option can fail. Do not soften a screen to keep an option alive, do not
present a screened-out option as the recommendation, and do not supply a
number that makes one look admissible. The handover then states that no
option passed, names the screen each option failed, and names what would have
to change for one to pass; the report commits to that statement. "Recommend
further study" is not that statement. A field emptied by screening with no
such statement is a send-back.

## Evaluation criteria

Each has five parts. A criterion missing one is not a criterion.

- Short title.
- Definition: the feature being evaluated.
- Unit of measure.
- Benchmark: the value that defines "good" on this criterion, taken from
  reasoning, historical precedent, or a current example. Averaging is least
  preferred.
- Formula: how changes in value affect desirability, comparative ("less is
  better") or absolute ("a night movement is better than a day movement").

```
Short title:      Casualties
Definition:       Casualties taken during the entire operation
Unit of measure:  Number of casualties
Benchmark:        136 casualties
Formula:          Less than 136 is an advantage; greater than 136 is a
                  disadvantage. Less is better.
```

## Weights and separate analysis

Every criterion carries a weight, and every weight states its rationale.
Each option was analyzed alone against the benchmark before any comparison,
so the finding can be "all options fail on cost".

## The decision matrix

Options across, criteria down, a rank per cell, lower rank preferred. The
unweighted total adds the ranks; the weighted total adds each rank times its
criterion weight, shown in parentheses. A weight of 1 needs no parenthetical.
Show both totals.

```
Criterion (weight):    Simplicity(1) Maneuver(2) Fires(1) Civil(1) Mass(2)
Option 1 rank:         2             2 (4)       2        1        1 (2)
Option 2 rank:         1             1 (2)       1        2        2 (4)

Option 1 total:  8 unweighted, 11 weighted
Option 2 total:  7 unweighted, 10 weighted
```

In the text, say where the judgment was subjective, and note that comparing
option by option is often more useful than comparing totals. Summarize the
result in the body.

## Commit to one course

Recommend one course: the action, the actor, and the date. The
decision-maker only approves or disapproves. Do not recommend alternatives.
Significant disagreement that survives the comparison is named in front of
the decision-maker, not smoothed away.
