# Collisions: tie-breaks

- Conclusion first versus hostile audience. The conclusion goes in the first
  paragraph. The indirect approach that softens the blow for a hostile reader
  is a deviation the operator may invoke, never a default the agent chooses.
- Analysis order versus presentation order. Not a conflict. The analysis
  ran in thinking order; the report presents in the reader's order,
  conclusion first.
- Named format versus exclusion list. Where the report uses a named format,
  whoever chose it, the format wins for exactly the elements its skeleton
  requires, and the exclusion list governs everything else. Name every
  excluded element on the format's row below, by its name on the exclusion
  list, not by the format's part names, in one line under
  `## Format elements`. The conclusion still leads, whatever number the
  skeleton gives it. This tie-break needs no deviation record.
