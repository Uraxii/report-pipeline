# Deriving a probability

- Start from the base rate of a comparable class of past cases, then combine
  it with case-specific evidence. Never drop the base rate because the case
  evidence feels compelling.
- Revising a running estimate: periodically discard it and re-derive from
  scratch rather than nudging it.
- A judgment that depends on a chain of prerequisite events: multiply the
  probabilities. Never average them.
- An easily recalled example is not evidence of high frequency. Discount it
  if you recalled it for vividness, recency, or personal relevance.
- A fresh indicator conflicts with a standing assumption: weight the indicator
  and re-examine the assumption.
- Comparing hypotheses: select the one with the fewest inconsistencies
  against the evidence, not the most support.
- A relevant variable is unknown: name it, weigh the values it plausibly
  holds, and lower the confidence. Never assume a default.
- Before citing a correlation, check all four cells: both present, only one,
  only the other, neither.
- Reviewing a past judgment: reconstruct the original uncertainty by asking
  whether the opposite outcome would have surprised you at the time.
