# Framing the environment and the problem

## Environment

Write what bears on the decision across five kinds of condition. Name the ones
that apply and say the rest are empty.

- Physical: place, hardware, capacity, distance, anything with a location.
- Social: people affected, their relationships, what they will tolerate.
- Political: who holds authority, what is already committed, whose approval
  the course needs.
- Informational: what is known, what is not, who controls the flow.
- Infrastructural: systems and services the course would run on or break.

Name which other parties' actions could degrade or block the course, not only
which conditions favour it.

## Actors

One row per actor relevant to the decision.

```
Actor              What it wants            Where that conflicts
Support team       Predictable hours        Coverage window the plan needs
Finance            Flat headcount cost      Any option that adds staff
```

Record conflicts actor against actor and actor against the deciding
organization's own goals. An actor with no conflict is irrelevant or
under-examined: decide which and say so.

## Problem

Three parts, in this order:

1. The tension between current conditions and desired conditions.
2. Which elements of the environment must change to close it.
3. The limitations that bound the response.

A problem stated as a solution ("we need to migrate to X") is not a problem
statement. Rewrite it as the tension it stood in for.

Then cast the same question as who, what, when, why, and how. Write both
versions.

Question came from someone else: get the problem statement approved before
working on it, and record who approved it. Approval not sought: record that.

## Terms

Define only terms used more narrowly than a reader would assume, or contested
inside the organization.

## Constraints

Itemized, one per line, never a paragraph: legal, resource, geographic,
schedule, and other operational limits. Every option gets checked against this
list.

```
C1  Cannot exceed the approved FY26 infra line, $340k
C2  Must retain data in-region under the DPA
C3  No change during the November freeze
```

## Structure class

Pick one and write why.

- **Well structured.** Nearly all needed information in hand, known methods
  apply, one verifiable answer exists. Often gets an answer, not an option
  comparison.
- **Medium structured.** The default. Some information missing, method mostly
  clear, more than one defensible answer.
- **Ill structured.** People disagree on the true problem, the desired end
  state, or whether it is reachable. Expect a package of measures.
